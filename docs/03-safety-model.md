# 03. 安全模型

## 1. 门禁列表

| 门禁 | 检查 | 不通过时 |
|---|---|---|
| G0 管理员 | 进程是 Administrator/SYSTEM | 停止 |
| G1 目标身份 | 型号 + 序列号 + 固件 + 容量 | 停止 |
| G2 启动属性 | 目标盘不是 Boot/System | 停止 |
| G3 源卷健康 | NTFS + Healthy | 停止 |
| G4 暂存空间 | 足够容纳缺失数据 + 余量 | 停止 |
| G5 源校验 | 源 ↔ 暂存 0 mismatch | 停止，源盘不动 |
| G6 取消标志 | 不存在 `CANCEL_*.flag` | 停止 |
| G7 DryRun | 默认只打印计划 | 不写盘 |
| G8 显式确认 | `-Execute` + `-ConfirmSerial` + 确认开关 | 不写盘 |

## 2. 身份识别

不要只依赖：

- 磁盘编号；
- 盘符；
- 容量；
- “磁盘 <N>”。

至少同时校验：

```text
Model    == <TARGET_MODEL>
Serial   == <TARGET_SERIAL>
Firmware == <TARGET_FIRMWARE>
Size     == <TARGET_SIZE>
IsBoot   == False
IsSystem == False
```

序列号是最后一道门禁。任何脚本在写盘前都必须重新读取序列号，不能复用启动时的缓存值。

## 3. 失败关闭矩阵

| 事件 | 行为 |
|---|---|
| 序列号不匹配 | 立即停止，不写盘 |
| 源卷不健康 | 停止，先做只读镜像/诊断 |
| 暂存空间不足 | 停止，不删除任何文件 |
| 比较 mismatch | 停止，源盘不动 |
| 卸载源卷失败 | 停止，不调用 DiskPart |
| DiskPart `clean` 失败 | 停止，保留日志 |
| 重建后卷不可枚举 | 停止，不继续回拷 |
| 回拷比较 mismatch | 停止，不删除暂存副本 |
| 用户取消/关闭窗口 | 以最后状态标记失败，保留证据 |

## 4. 状态标志的陷阱

真实事故中，`SourceDestroyed=true` 曾被写在 `clean` 调用**之前**。结果：

- `clean` 实际没有执行；
- 磁盘仍是 LDM 动态盘；
- 但状态文件已经宣称“源盘已销毁”；
- 操作者一度以为数据没了。

正确做法：

1. 只在 `diskpart clean` 返回成功、并且确认磁盘重新枚举后，才设置 `SourceDestroyed=true`；
2. 失败时不要相信状态标志，要直接检查：
   - `Win32_DiskPartition.Type`；
   - `Get-Disk`；
   - `Get-Volume`；
   - 原始 MBR（如可读）。
3. 旧运行的失败标记必须按 `RunStamp` 过滤，不能污染新运行。

## 5. DiskPart 安全规则

- 使用 `diskpart /s` 命令文件；
- 每次命令文件只包含明确的磁盘选择；
- 捕获退出码、stdout、stderr；
- 检查输出中的 `Virtual Disk Service error`、`没有选择磁盘`、`错误` 等；
- 不把多条命令拼成一行；
- 不在未确认 `select disk` 成功时执行 `clean`；
- `clean` 前再次确认目标序列号；
- `clean` 后等待 `Get-Disk` 重新枚举，设置超时；
- 初始化前检查 `PartitionStyle`，不要假设一定是 RAW。

## 6. 数据保留策略

在以下条件全部满足前，不要删除恢复镜像或暂存副本：

1. 新基本盘已通过全量比较；
2. `chkdsk /scan` 无问题；
3. 至少成功重启一次；
4. 关键应用能正常启动；
5. 用户确认数据可用；
6. 至少保留一段时间的独立备份。

建议至少保留：

- 一份整盘镜像（最坏情况恢复分区/文件系统）；
- 一份文件级暂存副本（快速找回单个文件）；
- 一份异地/离线副本。

删除镜像前问自己：**如果新盘明天无法挂载，我还能从哪里恢复？**

## 7. 威胁模型

| 威胁 | 缓解 |
|---|---|
| 选错磁盘 | 型号+序列号+固件+启动属性 |
| 旧状态标记 | RunStamp 过滤、时间戳校验 |
| 活日志导致 mismatch | 停止写入服务、排除日志目录或接受差异 |
| 杀毒软件拦截 PUA | 不绕过；明确排除或接受差异 |
| 断电/崩溃 | 每阶段状态、可恢复脚本、保留暂存 |
| 用户误点 | DryRun 默认、显式确认参数 |
| DiskPart 交互时序 | `/s` 命令文件、等待进程退出 |
| 卷卸载后误以为数据丢失 | 先 `online volume`/`assign letter`，不要格式化 |

## 8. 操作者检查清单

写盘前逐项确认：

- [ ] 目标盘序列号已人工核对；
- [ ] 目标盘不是系统/启动盘；
- [ ] 暂存副本已全量比较，0 mismatch；
- [ ] 恢复镜像/暂存副本在独立健康磁盘；
- [ ] 没有取消标志；
- [ ] 已关闭所有从源盘运行的程序；
- [ ] 已停止会写源盘的日志服务；
- [ ] 已确认回拷目标盘符；
- [ ] 已阅读失败恢复步骤；
- [ ] 已获得用户明确授权。
