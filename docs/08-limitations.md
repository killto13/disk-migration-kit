# 08. 限制与风险

## 1. 范围限制

- 仅支持**单块磁盘**上的 LDM 简单卷；
- 不支持跨磁盘 extent、带区卷、镜像卷、RAID-5；
- 不支持 Storage Spaces、硬件 RAID、BitLocker；
- 不支持系统盘/启动盘/页面文件盘/休眠盘；
- 目标为 MBR 基本盘，受 2 TiB 限制；
- 文件系统默认 NTFS；未验证 exFAT/ReFS/FAT32；
- 未验证 4K 原生扇区、EFS 加密文件、重复数据删除、压缩卷。

## 2. 一致性限制

- 在线复制不是应用一致性快照；
- 数据库、虚拟机、正在写入的日志可能处于不一致状态；
- 复制前应停止所有写入源盘的程序/服务；
- 如果无法停止，必须接受“日志/临时文件可能 mismatch”。

## 3. 文件差异限制

- 活日志、临时文件、缓存可能在复制期间变化；
- 杀毒软件可能拦截/隔离 PUA 文件；
- 文件锁可能导致读取错误；
- 长路径、权限、ACL/所有者可能影响复制；
- 任何 mismatch 都必须被解释，不能“跳过继续”。

## 4. 硬件限制

- 老式机械盘可能有坏道/读取错误；
- SMART “Healthy” 不等于没有坏道；
- `ReadErrorsUncorrected > 0` 是停止信号；
- 重建/格式化会增加磁盘压力；
- 电源中断可能导致分区/文件系统处于中间状态。

## 5. 软件限制

- DiskPart 输出受系统语言影响，错误检测需要兼容本地化文本；
- PowerShell 5.1 对 UTF-8 无 BOM 文件/泛型 List 有兼容性坑；
- Robocopy `/MT` 与 `/IPG`、`/EFSRAW` 存在兼容性限制；
- 不同 Windows 版本的 `Get-Disk`/`Get-Partition` 行为可能不同；
- 动态盘在 Storage cmdlet 中可能不枚举，需要 WMI/DiskPart 交叉验证。

## 6. 参考实现声明

本项目是**参考实现**，不是经过大规模生产验证的商业工具：

- 只在一个真实硬件/Windows 10 环境上完整跑通；
- 没有单元测试/集成测试矩阵；
- 没有针对所有磁盘控制器/驱动验证；
- 不提供数据恢复保证；
- 使用前必须在虚拟机/克隆盘上验证。

## 7. 数据保留

即使迁移成功，也建议保留：

- 一份整盘镜像；
- 一份文件级暂存副本；
- 一份离线/异地副本。

删除镜像前确认：

1. 新盘通过全量比较；
2. `chkdsk /scan` 无问题；
3. 至少成功重启一次；
4. 关键应用正常；
5. 用户明确确认。

## 8. 法律与合规

- 不要迁移/复制你无权处理的数据；
- 不要绕过组织的数据安全策略；
- 不要把包含个人数据的镜像/日志上传公共网络；
- 遵守当地法律和软件许可。
