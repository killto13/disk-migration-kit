# 07. 失败恢复手册

> 恢复的第一步永远是“停止进一步写入”，而不是“再运行一次”。  
> 下面所有命令都必须先核对磁盘/卷编号，且不要在未确认状态时格式化。

## 1. 先判断停在哪一阶段

| 现象 | 可能阶段 | 数据状态 |
|---|---|---|
| 源盘符正常，文件可读 | 复制/比较阶段 | 源数据完好 |
| 源盘符消失，但分区表仍是 LDM | 卷被 dismount/offline | 数据通常完好 |
| `Get-Disk` 显示 RAW / 无分区 | clean 已执行 | 分区表已丢，数据区可能仍在 |
| 新卷已创建但文件少 | 回拷未完成 | 暂存副本是主来源 |
| 比较 mismatch | 复制/回拷不完整 | 源/暂存至少一侧完整 |

## 2. 场景 A：复制或比较失败

症状：

- 源盘仍可读；
- 暂存副本不完整或 mismatch。

处理：

1. 不要清盘；
2. 保留日志和进度 CSV；
3. 分类 mismatch：内容/长度/缺失/读取错误；
4. 停止写入源盘的服务/日志；
5. 重新复制差异或重新比较；
6. 0 mismatch 后才继续。

## 3. 场景 B：卷被卸载/脱机，但分区表仍是 LDM

症状：

- 源盘符消失；
- `Win32_DiskPartition.Type` 仍是 `Logical Disk Manager`；
- DiskPart `detail disk` 显示卷“脱机”。

处理（只恢复挂载，不格式化）：

```text
select disk <N>
select volume <V>
online volume
assign letter=<SOURCE>
exit
```

然后检查：

```powershell
Get-Volume -DriveLetter <SOURCE>
Get-Disk -Number <N>
Get-Partition -DriveLetter <SOURCE>
```

如果卷恢复、NTFS/Healthy，先做文件数和关键文件哈希核对。

> 不要因为盘符消失就执行 `clean` 或 `format`。

## 4. 场景 C：clean 已执行，但新分区/卷未建立

症状：

- `Get-Disk -Number <N>` 显示 RAW 或无分区；
- 原 LDM 分区不存在；
- 暂存副本/镜像完整。

处理：

1. 确认暂存副本通过全量比较；
2. 初始化 MBR；
3. 创建主分区；
4. 分配盘符；
5. 格式化 NTFS；
6. 从暂存副本回拷；
7. 再次全量比较；
8. `chkdsk /scan`。

如果没有可信的暂存副本，不要继续；先从整盘镜像恢复或走专业恢复。

## 5. 场景 D：回拷不完整/比较失败

症状：

- 新基本盘已存在；
- 文件数/字节数不足；
- 比较 mismatch。

处理：

1. 保留暂存副本；
2. 重新运行回拷（不要 `/MIR`、不要 `/PURGE`）；
3. 重新比较；
4. 若反复失败，检查：
   - 目标盘健康；
   - 文件锁/杀毒软件；
   - 路径长度/权限；
   - 磁盘空间。

## 6. 场景 E：目标盘选错

症状：

- 序列号与预期不符；
- 目标盘是系统/启动盘；
- 目标盘上有不该被清空的数据。

处理：

1. **立即停止**；
2. 不执行任何 clean/format；
3. 记录实际序列号/型号；
4. 重新识别正确磁盘；
5. 如果已经误写，停止使用该盘，走镜像恢复。

## 7. 场景 F：源盘出现读取错误

症状：

- SMART `ReadErrorsUncorrected > 0`；
- 事件日志 disk Event ID 7；
- 比较出现 read error。

处理：

1. 停止重建；
2. 不再大规模读取源盘；
3. 用只读镜像工具（如 ddrescue）尽量提取；
4. 从已有镜像/暂存副本恢复；
5. 不要对源盘 `chkdsk /f`、Surface Scan 或修复写入。

## 8. 恢复后的核对

无论哪种恢复，至少核对：

- 磁盘型号/序列号/固件；
- 分区样式（MBR/GPT）；
- 目标卷 NTFS/Healthy；
- 文件数/目录数/字节数；
- 关键文件 SHA-256；
- `chkdsk /scan`；
- SMART 读取错误计数；
- 事件日志无 disk Event ID 7。

## 9. 不要做的事

- 不要 `diskpart clean` 后再“试试看”；
- 不要 `format` 后再尝试恢复文件；
- 不要对唯一副本执行 `/MIR`；
- 不要绕过杀毒软件复制 PUA；
- 不要在源盘上运行 `chkdsk /f`；
- 不要把“盘符消失”当成“数据没了”；
- 不要删除暂存副本，直到新盘通过验收并稳定运行。
