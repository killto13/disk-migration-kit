# Portable Software / 便携软件

[简体中文](README.zh-CN.md) | [English](README.en.md)

This folder contains the packaged portable software for convenience.

- `EDiskMigration-portable-20261125.zip` — extract and run `EDiskMigration.exe`
- `EDiskMigration.exe` — the GUI executable; it needs the `scripts/` and `docs/` folders from the repository or the zip
- `EDiskMigration-SHA256SUMS.txt` — SHA-256 checksums

> The target physical disk is erased at step 4. Use only on a non-system/non-boot disk, and test on a VM or disposable disk first.
